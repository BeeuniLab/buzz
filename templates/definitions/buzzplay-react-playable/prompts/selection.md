# Template Selection

BuzzPlay React playable template for mobile-first interactive content.

Use when:
- The request is a short playable post, meme game, reaction challenge, character toy, interactive story, personality quiz, reveal mechanic, score/result loop, or social challenge.
- The user gives a simple idea and expects it to become a polished touch-first experience with immediate play, feedback, and a shareable result.
- The experience benefits from React components, stateful UI, animation, asset handling, reusable controls, or future extensibility beyond one HTML file.
- The output should fit BuzzPlay feed/preview usage: portrait-first, fast to understand, playable on mobile, and complete on the first screen.

Avoid when:
- The user explicitly asks for a dashboard, CRUD app, backend-heavy platform, long-form website, blog, e-commerce app, or SEO landing page.
- The user explicitly wants a single-file HTML canvas creative with no React structure.

Built with:
- React, Vite, TypeScript, Tailwind, ShadCN UI, Lucide Icons, React Router, Cloudflare Workers serving, and `src/asset_map` awareness for uploaded media.
