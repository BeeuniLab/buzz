# Game Type Recipes

Use this skill when the prompt is broad, such as "make a game about this image", "make it fun", "create an interactive meme", "make a challenge", or "turn this into playable content".

Pick one primary recipe. Do not combine many genres unless the user asks for a larger game.

## How To Choose

- If the prompt has a strong verb, build around it: dodge, catch, slice, tap, drag, merge, sort, quiz, reveal, feed, protect, clean, aim, or upgrade.
- If the prompt is mostly a subject, choose the shortest fun loop that makes the subject react.
- If uploaded media is central, make the media the avatar, target, board, prop, sticker, background, or reveal object.
- If the user asks for "funny", prefer exaggerated feedback, surprise reveal, fast failure/retry, or absurd scoring.
- If the user asks for "cute/cozy", prefer collection, care, sorting, gentle upgrade, or reveal loops over failure-heavy action.

## Presentation References

Use references as interaction and polish patterns, not as IP to copy.

- **Microgame pacing:** one obvious command, a short countdown or prompt, instant consequence, funny result.
- **Runner/flappy pacing:** automatic motion, one input, clear obstacle rhythm, fast retry.
- **Merge toy:** next piece preview, soft physics or snap, unlock ladder, celebratory merge pop.
- **Arcade blaster:** strong target silhouettes, warning states, hit flashes, wave clear text.
- **Rhythm/timing:** persistent hit lane, beat-synced scale/flash, perfect/good/miss language.
- **Clicker/idle:** center toy, resource popups, affordable upgrade glow, visible world growth.
- **Puzzle board:** stable geometry, valid/invalid preview, ordered animations, clear completion.
- **Quiz/result:** expressive choice cards, progress dots, dramatic reveal, shareable result title.
- **Photo/media toy:** real asset as star, invisible regions, props/frames/tint, no permanent debug marks.
- **Pixel arcade:** limited palette, chunky UI, sprite flash, hit stop, blocky particles.

## Match Type To Subject

- **Food:** slice, catch, merge, feed, sort, timing.
- **Pet/character:** care toy, dodge/collect, reaction tap, dress-up/result, choice story.
- **Sports:** timing shot, dodge/collect, target hit, runner lane, score challenge.
- **Music/dance:** rhythm tap, timing lane, call-and-response, stage reveal.
- **Photo/person/media:** hidden object, sticker props, spotlight reveal, tap zones, reaction toy.
- **Meme/social:** choice/result, tap chaos, ranking quiz, absurd clicker, reveal toy.
- **City/business:** tycoon, sorting logistics, route/timing, upgrade loop.
- **Space/monster/action:** shooter, arena growth, dodge survival, boss tap target.
- **Cozy/cute:** collection, care, sorting, gentle merge, progress reveal.
- **Horror/suspense:** timing, hidden object, light/avoid, short jump scare reveal.

## Borrow Responsibly

- Borrow a pattern's pacing, feedback, state clarity, and interaction shape.
- Do not use copyrighted names, characters, logos, sprites, sounds, or direct level layouts.
- Rename mechanics into the user's subject language.
- If a reference is too complex, keep its core feeling and reduce to one 15-30 second loop.

## Avoid

- Do not stack three unrelated mechanics into one tiny post.
- Do not make the user read the rules before touching anything.
- Do not choose a dense strategy/RPG loop when the prompt only needs a shareable microgame.
- Do not clone a famous game's branding or assets; translate the interaction into the user's theme.
